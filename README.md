# 18분 상황실 — A House of Dynamite 감성의 핵 위기 의사결정 게임

같은 18분을 세 개의 의자로 산다. 백악관 상황실 당직 장교 → 국가안보 부보좌관 → 대통령.
앞 막에서 올린 보고서와 권고가 뒷 막의 책상에 그대로 놓인다.

## 플레이
- `index.html` 하나로 동작한다. 브라우저에서 열거나 GitHub Pages로 서빙.
- 시작 화면에서 시나리오 코드(SCN-xxxx)와 속도(×1 실시간 18분 / ×2 / ×3)를 고른다.
- 플레이 중 `P` 또는 `Esc`(상단 '일시정지' 버튼)로 시계를 멈춘다. 탭을 벗어나면 자동으로 멈춘다. 직통 전화는 숫자키 `1`~`4`로 응답할 수 있다.
- 매판 달라지는 것: 발사 주체(북한 지상·북한 잠수함·러시아 오발·러시아 명령체계 밖 부대·미상·위성 오경보), 발사 지점(동해·오호츠크·베링해·북태평양 + 좌표 지터), 표적 도시 8곳, 요격 자산(GBI 1~3발, 이지스), 대통령 위치, 2차 항적(실제/허위), 돌발 이벤트 12종 중 4개.

## 구조
- **1막 상황실** — 당직 장교. 회의 소집, 통보, 1차 판단, 요약 보고서(확인된 것만 체크), 오보 정정, 회의선 재연결, 직통 전화 응답. 큰 결정은 회의선이 하고 당신은 전달한다.
- **2막 요격** — 부보좌관. GMD 킬체인 콘솔. GBI 교전, 이지스, 2차 표적 자산 배분(밴덴버그 예비·이지스), 민방위 경보, DEFCON, 핫라인, 동맹, 풋볼 준비, COG, 옵션 폴더 구성.
- **3막 대통령** — 핵 지휘 인증(비스킷 코드 대조), 옵션 폴더(전면/제한/재래식/보류), 정상 통화, 참모 압박, 한 번의 결정.

## 기술
- 순수 HTML/CSS/JS 단일 파일. 외부 의존성은 Google Fonts뿐.
- 지도: Natural Earth 50m 해안선(world-atlas)을 RDP 단순화해 내장(`data/land.js`), 북태평양 중심 방위등거리도법, 대권 궤적.
- 참모 AI: claude.ai 아티팩트의 `sample` 런타임 캐퍼빌리티로 참모 8명이 실시간 대답. 아티팩트 밖(GitHub Pages)에서는 자동으로 대본 모드.
- 음악: 실제 OST가 아닌 WebAudio 절차 생성 긴장 음악(드론 + 심장박동 펄스, TTI에 따라 가속).

## 빌드
`src/`와 `data/`를 수정한 뒤 `python3 scripts/build.py` 로 `index.html`을 다시 조립한다.
